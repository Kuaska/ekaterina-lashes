# Екатерина — ламинирование ресниц, Тюмень

Статический сайт-визитка с онлайн-записью и кабинетом мастера.
Без сборки и зависимостей: открывается как обычный HTML.

## Структура

```
index.html      — лендинг
admin.html      — кабинет мастера (вход по паролю)
styles.css      — стили лендинга
admin.css       — стили кабинета
js/store.js     — данные и логика расписания (localStorage)
js/site.js      — лендинг: услуги, календарь, слоты, форма
js/admin.js     — кабинет: заявки, календарь, услуги, настройки
fonts/          — Cormorant Garamond + Manrope (локально)
images/         — фотографии работ
```

## Как запустить

Открыть `index.html` в браузере — или поднять локальный сервер:

```
npx serve .
```

## Кабинет мастера

`admin.html`, пароль по умолчанию — `ekaterina`
(меняется в `js/admin.js`, константа `ADMIN_PASSWORD`).

Возможности:

- заявки: подтверждение, «выполнено», отмена, редактирование, удаление;
- недельный календарь: закрыть день или отдельные часы;
- услуги: названия, описания, цены, длительность, вкл/выкл;
- настройки: рабочие дни и часы, обед, лимит записи вперёд,
  срок предварительной брони, контакты;
- экспорт/импорт всех данных в JSON, демо-данные, сброс.

## Как это работает

Заявка с сайта сразу занимает слот как предварительная бронь
(`holdHours`, по умолчанию 24 часа). Если мастер не подтвердил —
слот освобождается автоматически.

Все данные хранятся в `localStorage` браузера. Это значит:
заявки видны только на том устройстве, где их оставили.
Для реального приёма заявок нужен общий бэкенд: сервер, который хранит
записи и отдаёт их кабинету мастера с любого устройства.
