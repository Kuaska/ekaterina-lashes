# Екатерина — ламинирование ресниц, Тюмень

Сайт с онлайн-записью и кабинетом мастера. Данные хранятся на сервере,
поэтому заявки с телефона клиента сразу видны в кабинете на компьютере.

## Запуск

Нужен Node.js 18 или новее. Зависимостей нет.

```
node server.js
```

или

```
npm start
```

Открыть:

- сайт — http://localhost:4173
- кабинет — http://localhost:4173/admin.html

Пароль по умолчанию — `ekaterina`. Меняется переменной окружения
`ADMIN_PASSWORD` при запуске:

```
set ADMIN_PASSWORD=новый-пароль && node server.js
```

Кабинет открывается с того же сервера, поэтому заявки, услуги и расписание
одинаковы на всех устройствах, которые заходят на этот адрес.

## Как открыть с телефона

Компьютер и телефон должны быть в одной сети. Узнайте адрес компьютера
(`ipconfig` → IPv4) и откройте на телефоне `http://192.168.x.x:4173`.
Если не открывается — разрешите Node.js в брандмауэре Windows.

Чтобы сайт был доступен из интернета, этот же `server.js` ставится на VPS
или Render/Railway: команда запуска та же.

## Структура

```
server.js       — сервер: статика, API, авторизация, расписание
index.html      — лендинг
admin.html      — кабинет мастера
styles.css      — стили лендинга
admin.css       — стили кабинета
js/store.js     — данные, расчёт слотов, форматирование
js/site.js      — лендинг: услуга, календарь, слоты, форма
js/admin.js     — кабинет: заявки, календарь, услуги, настройки
fonts/          — Cormorant Garamond + Manrope (локально)
images/         — фотографии работ
data/db.json    — база записей (создаётся при первом запуске)
```

## Кабинет мастера

- заявки: подтверждение, «выполнено», отмена, правка, удаление, поиск;
- недельный календарь: закрыть день или отдельные часы;
- услуга: название, описание, цена, длительность, вкл/выкл;
- настройки: рабочие дни и часы, обед, лимит записи вперёд,
  срок предварительной брони, телефон и Telegram;
- экспорт и импорт JSON, демо-записи, полный сброс.

## Как работает запись

Заявка сразу занимает слот как предварительная бронь (`holdHours`,
по умолчанию 24 часа). Мастер подтверждает её в кабинете; если не
подтвердил — слот освобождается автоматически.

Сервер сам проверяет занятость: два клиента не смогут занять одно время,
даже если отправят форму одновременно.

## Уведомления в Telegram (необязательно)

Создайте бота через @BotFather, узнайте `chat_id` и запустите:

```
set TELEGRAM_BOT_TOKEN=123456:ABC && set TELEGRAM_CHAT_ID=123456789 && node server.js
```

Новая заявка придёт сообщением в Telegram. SMS в России платные
(около 2–4 ₽ за сообщение), поэтому уведомления идут в Telegram.

## Резервная копия

Все данные — в `data/db.json`. Достаточно скопировать этот файл.
В кабинете также есть кнопка «Скачать данные» (JSON).

## Фотографии

В `images/` — демонстрационные снимки (Unsplash, свободная лицензия)
и одна реальная работа мастера. Их стоит заменить на актуальные работы.
